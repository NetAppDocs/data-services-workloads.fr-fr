== Ajouter un système

Enregistrez le projet que vous souhaitez gérer afin que Workload Factory inclue ses pools de stockage dans chaque région.

.Avant de commencer
Ajoutez les informations d’identification de votre projet Google Cloud NetApp Volumes dans Workload Factory. link:add-credentials.html["Apprenez à ajouter des identifiants"].

.Étapes
. Dans le menu NetApp Console, sélectionnez *Storage* > *Management* > Systems, puis *Add system* > *Google Cloud Platform*.
. Sous *Google Cloud NetApp Volumes*, sélectionnez *Discover*.
. Saisissez un nom pour le système.
. Sélectionnez les informations d’identification du système.
. Vous pouvez sélectionner une région si vous le souhaitez. Si vous n'en sélectionnez pas, le système couvre toutes les régions.
+

NOTE: La région ne limite pas la découverte. Workload Factory découvre les pools de stockage dans toutes les régions pour les informations d'identification. La région que vous sélectionnez détermine ce que le système affiche sur le canevas et ce que la conformité et DRaaS utilisent.

. Cliquez sur *Discover*.


.Résultat
La NetApp Console affiche le système sur la page Systèmes. Vous pouvez ajouter autant de systèmes que vous le souhaitez pour les mêmes identifiants.
