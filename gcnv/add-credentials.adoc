= Ajoutez les informations d'identification de Google Cloud NetApp Volumes à NetApp Workload Factory
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Ajoutez et gérez les identifiants de votre fournisseur de cloud afin que NetApp Workload Factory dispose des autorisations dont il a besoin pour déployer et gérer des ressources dans les comptes de votre fournisseur de cloud.



[[overview]]
== Aperçu

Vous pouvez ajouter des informations d'identification Google Cloud NetApp Volumes à partir de la page Informations d'identification dans la NetApp Console. La console fournit des instructions de configuration guidée et un lien vers la documentation afin que vous puissiez effectuer la configuration Google Cloud requise, puis revenir pour terminer l'ajout des informations d'identification.

Utilisez ce flux de travail pour accorder à Workload Factory les autorisations nécessaires pour découvrir, analyser et gérer les ressources de votre environnement Google Cloud.

La création des identifiants comporte trois étapes :

* Étape 1 : Sélectionnez le niveau d’autorisation que vous souhaitez accorder à Workload Factory.
* Étape 2 : Créez et validez un compte de service Google Cloud, puis sélectionnez le projet Google Cloud à gérer.
* Étape 3 : Saisissez un nom pour les identifiants et ajoutez les identifiants.


.Avant de commencer
Vous aurez besoin d'identifiants pour vous connecter à votre compte Google Cloud.

.Étapes
. Connectez-vous à l' https://console.netapp.com/["Console NetApp"^].
. Dans le menu, sélectionnez *Charges de travail* > *Administration* > *Identifiants*.
. Sur la page Informations d'identification, sélectionnez *Ajouter des identifiants*.
. Sélectionnez *Google Cloud NetApp Volumes* comme fournisseur de cloud.
. Sur la page Ajouter les informations d’identification Google Cloud NetApp Volumes, remplissez chaque section sous *Configuration des autorisations*.




[[step-1-create-permission-policies]]
=== Étape 1 : Créer des stratégies d’autorisation

.Étapes
. Sous *Créer des stratégies d’autorisation*, *Afficher, planifier et analyser* est sélectionné par défaut. Cette stratégie d’autorisation vous permet de consulter les pools de stockage Google Cloud NetApp Volumes, d’obtenir des informations sur l’état du système, d’obtenir l’analyse de bonne architecture pour vos systèmes et d’explorer les économies.
. Facultatif : sélectionnez *Opérations et correction* si vous souhaitez également que Workload Factory gère les ressources Google Cloud NetApp Volumes et corrige les problèmes de configuration.
. Veuillez consulter les instructions de configuration link:https://docs.netapp.com/us-en/storage-management-google-cloud-netapp-volumes/task-set-up-gcnv.html#set-up-a-service-account["Configurer Google Cloud NetApp Volumes"^] avant de continuer.




[[step-2-create-the-google-cloud-service-account]]
=== Étape 2 : Créer le compte de service Google Cloud

.Étapes
. Développez *Configurez votre environnement Google Cloud*.
. Suivez les étapes 1 à 5 affichées pour créer un compte de service Google Cloud.
. Copiez l'adresse e-mail du compte de service.
. Retournez dans Workload Factory, collez l'adresse e-mail dans le champ *GCP service account* et sélectionnez *Validate credentials*.
. Une fois la validation terminée, dans le menu déroulant *Projects*, sélectionnez le projet Google Cloud que vous souhaitez que Workload Factory gère. REMARQUE : La liste Projects n’est pas disponible tant que les informations d’identification du compte de service n’ont pas été vérifiées.




[[step-3-enter-the-credentials-name]]
=== Étape 3 : Saisissez le nom des informations d’identification

.Étapes
. Développez *Nom des identifiants*.
. Dans le champ *Nom*, saisissez un nom pour les informations d’identification en utilisant uniquement des caractères alphanumériques. Les caractères spéciaux et les espaces ne sont pas autorisés.
. Sélectionnez *Add*.


.Résultat
Les identifiants Google Cloud NetApp Volumes sont ajoutés à votre compte et sont disponibles pour les opérations Workload Factory prises en charge.
