= Démarrage rapide pour Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Pour commencer à utiliser Google Cloud NetApp Volumes, attribuez votre rôle dans NetApp Console, ajoutez des informations d’identification et découvrez un système.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"] link:../gcnv/add-roles.html["Attribuer des rôles"]
[role="quick-margin-para"]
Depuis la NetApp Console, attribuez les rôles corrects aux membres.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["Ajouter les identifiants"]
[role="quick-margin-para"]
Dans la console NetApp, ajoutez les identifiants Google Cloud NetApp Volumes.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"] link:../gcnv/create-discover-systems.html["Ajouter un système"]
[role="quick-margin-para"]
Dans la NetApp Console, découvrez un système à l’aide des identifiants, du projet Google Cloud et de la région prise en charge.
