= Attribuer des rôles à Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Vous devez attribuer les rôles appropriés aux membres dans NetApp Console pour commencer à travailler avec Google Cloud NetApp Volumes. Pour plus d'informations, consultez link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Découvrez les rôles d’accès à NetApp Console pour tous les services"^].



[[assign-roles-to-the-service-account-member]]
== Attribuer des rôles au membre du compte de service

. Connectez-vous à  https://docs.netapp.com/us-en/console-setup-admin/task-logging-in.html["NetApp Console"^].
. Sélectionnez *Administration* puis *Identity and access*.
. Sélectionnez le menu Actions image:screenshot_gallery_options.gif["Une icône avec trois points."] à côté du membre auquel vous souhaitez attribuer un rôle et sélectionnez *Ajouter un rôle*.
. Pour ajouter un rôle, complétez les étapes dans la boîte de dialogue :
+
.. Sélectionnez un dossier ou un projet : choisissez le niveau de votre hiérarchie de ressources pour lequel le membre doit disposer d’autorisations.
+
Si vous sélectionnez un dossier, le membre dispose des autorisations nécessaires pour accéder à tout ce qui se trouve dans ce dossier.

.. Dans le menu déroulant *Catégorie*, sélectionnez la catégorie de rôle *Application*. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Découvrez les rôles d'accès"^].
.. Dans le menu déroulant *Rôle*, sélectionnez un rôle qui confère au membre les autorisations nécessaires pour accéder aux ressources associées au dossier ou au projet que vous avez sélectionné.
+
*Important:* Vous devez ajouter l'un ou les deux rôles suivants :

+
*** _Administrateur de Google Cloud NetApp Volumes_ OU
*** _Visionneuse Google Cloud NetApp Volumes_


.. Ajouter un rôle : Si vous souhaitez donner accès à des dossiers ou projets supplémentaires au sein de votre organisation, sélectionnez *Ajouter un rôle*, spécifiez un autre dossier, projet ou catégorie de rôle, puis sélectionnez une catégorie de rôle et un rôle correspondant.


. Sélectionnez *Ajouter de nouveaux rôles*.
