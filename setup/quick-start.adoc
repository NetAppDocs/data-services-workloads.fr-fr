= Démarrage rapide pour NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory est accessible aux utilisateurs en tant que service de données cloud depuis NetApp Console. Pour commencer à utiliser Workload Factory, inscrivez-vous et créez un compte dans NetApp Console, puis ajoutez les identifiants du fournisseur de cloud afin que Workload Factory puisse gérer directement vos ressources et optimiser vos charges de travail.

Avant de commencer, vous devriez avoir une compréhension de link:learn-about-workload-factory.html["Workload Factory"].



[[sign-up-and-log-in-to-workload-factory-from-netapp-console]]
== Inscrivez-vous et connectez-vous à Workload Factory depuis NetApp Console

link:sign-up-and-log-in.html["Inscrivez-vous et connectez-vous à Workload Factory depuis NetApp Console"]

Ensuite, sélectionnez le lien *Démarrage rapide* correspondant à votre fournisseur de cloud pour commencer.
