= Créez un plan de déploiement pour Amazon EVS à l'aide de l'outil de conseil en migration
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Depuis le centre de planification VMware, vous pouvez lancer Amazon EVS migration advisor pour vous aider à créer un plan de migration personnalisé selon vos besoins.

Vous pouvez créer un plan de déploiement pour migrer des machines virtuelles vers Amazon Elastic VMware Service et utiliser des systèmes de fichiers Amazon FSx for NetApp ONTAP personnalisés comme banques de données externes. Les options proposées par l'assistant de migration peuvent varier selon l'outil utilisé pour collecter les données d'inventaire des machines virtuelles.



[[requirements]]
== Exigences

* Vous devez disposer d'un nom d'utilisateur et d'un mot de passe pour accéder à Workload Factory. Si vous n'y avez pas accès, créez un compte dès maintenant. Consultez les instructions link:quick-start-vmware.html["ici"].
* Vous devez disposer d'un abonnement à Amazon Elastic VMware Service.




[[steps]]
== Étapes

. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *VMware*.
+
Le centre de planification est affiché.

. Sélectionnez dans la liste l'inventaire de machines virtuelles que vous souhaitez utiliser pour élaborer un plan de déploiement, puis sélectionnez *Commencer la planification* sur cette ligne.
. Sélectionnez *EVS* dans le menu déroulant qui apparaît.
+
L'assistant *Préparation à l'intégration au cloud AWS* s'affiche.

. Veuillez saisir les informations requises.


[discrete]
===== Spécifier

. Dans la section « Téléchargement de la configuration des machines virtuelles », consultez les informations relatives à l’ensemble de données utilisé pour créer un plan de migration. La section « Résumé de l’inventaire des machines virtuelles » est renseignée à partir du fichier d’inventaire et indique le nombre de machines virtuelles et la capacité de stockage totale.
. Dans la section _Considérations relatives à l'inventaire des machines virtuelles_, sélectionnez les options permettant de filtrer la liste des machines virtuelles que vous souhaitez migrer :
+
.. *Région* : sélectionnez la région où les systèmes de fichiers Amazon FSx for NetApp ONTAP seront déployés. Pour des performances et une rentabilité optimales, il s'agit généralement de la même région que celle où votre Amazon EC2 SDDC existant est déployé.
.. Choisissez un niveau de performance prévisionnel pour les machines virtuelles de cette région. Nous vous recommandons de commencer par un nombre d'IOPS plus faible. Vous pourrez augmenter les IOPS SSD provisionnées une fois le système de fichiers créé, à mesure que les charges de travail sont migrées ou déployées.
+
*** *Performances standard à élevées* : Pour les machines virtuelles avec des taux d’E/S moyens compris entre 20 et 5 000 IOPS.
*** *Très hautes performances* : Pour les machines virtuelles avec des taux d’E/S moyens supérieurs à 5 000 IOPS.
*** *Performances très faibles* : Pour les VMs dont le taux d’E/S moyen est inférieur à 20 IOPS.




. Dans la section _Capacité cible et considérations de protection_, choisissez parmi plusieurs options de stockage :
+
.. *Stockage des VM à prendre en compte*: Choisissez si les datastores créés pour chaque VM intégrée sont dimensionnés en fonction de leur taille actuellement utilisée (recommandé) ou de leur taille provisionnée.
+
Les banques de données externes seront mises en œuvre à l’aide de volumes de système de fichiers Amazon FSx for NetApp ONTAP.

.. *Taux moyen de réduction des données* : choisissez parmi les trois taux courants de réduction des données. Sélectionnez « 1:1 - No reduction », « 1:1.25 - 20% reduction » ou « 1:1.5 - 33% reduction ».
+
Sélectionnez *Aide au choix* si vous hésitez sur le ratio à privilégier. La boîte de dialogue _Assistant de réduction des données_ s'affiche. Sélectionnez les affirmations qui s'appliquent à votre parc de machines virtuelles et à votre espace de stockage. L'assistant vous recommandera un taux de réduction des données approprié. Sélectionnez *Appliquer* pour utiliser le ratio recommandé.

.. *Pourcentage de marge de manœuvre* : Saisissez le pourcentage de croissance de capacité ajouté à la capacité de vos systèmes de fichiers FSx for ONTAP.
+
Notez que si vous sélectionnez une valeur inférieure à 20 %, vous ne pourrez pas créer d'instantanés de volume pour la protection et les sauvegardes à long terme.

.. *Protection par instantané de machine virtuelle* : Activez cette option pour protéger les machines virtuelles à l’aide d’instantanés.


. Sélectionnez *Suivant*.


[discrete]
===== Sélectionner

. Sur la page *Sélectionner les machines virtuelles*, choisissez dans la liste les machines virtuelles que vous souhaitez inclure dans la migration AWS. Vous pouvez filtrer la liste selon l'état d'alimentation de chaque machine virtuelle, ainsi que le centre de données et le cluster où elle se trouve.
+
Dans la liste des machines virtuelles, vous pouvez choisir les types d'informations à afficher sous forme de colonnes. Par exemple, la sélection de _IOPS de lecture maximale_ affiche une colonne indiquant les IOPS de lecture maximales pour chaque machine virtuelle.

. Vous pouvez, si vous le souhaitez, choisir d’optimiser le déploiement en fonction des coûts ou de la capacité de récupération.
+
** *Coût* : Workload Factory sélectionne dans la liste les machines virtuelles présentant une densité d’E/S plus faible. Cela permet de réduire les besoins en ressources.
** *Récupérabilité* : Workload Factory choisit dans la liste les VM les plus faciles à copier rapidement en local. Cela offre des temps de récupération rapides en cas de perturbations.


. Sélectionnez *Suivant*.


[discrete]
===== Design

* Sur la page *d’attribution du stockage de l’instance ClassReview*, examinez les informations de la VM, les règles de classification des volumes, les affectations de volumes et la liste des volumes qui seront migrés dans le cadre du déploiement, puis sélectionnez *Suivant*.


[discrete]
===== Plan de révision

. Sur la page *Examiner le plan*, consultez les estimations d'économies mensuelles et les estimations de coûts pour toutes les machines virtuelles que vous prévoyez de migrer.
+
En haut de la page, vous trouverez une estimation des économies mensuelles pour les systèmes de fichiers FSx for ONTAP et les volumes EBS. Vous pouvez développer chaque section pour consulter les détails de la configuration de système de fichiers suggérée, la ventilation des économies estimées, les hypothèses et les clauses de non-responsabilité techniques.

+
Le plan de migration est automatiquement enregistré par défaut dans la liste des plans du centre de planification.

. Si vous le souhaitez, vous pouvez exporter le plan de migration sous forme de fichier PDF ou CSV en sélectionnant *Gérer le plan* en haut à droite de la page, puis *Télécharger un rapport (.pdf)* ou *Télécharger le déploiement du stockage VM (.csv)*.
+
Le fichier .csv crée une carte de toutes les machines virtuelles incluses dans le plan de migration, ainsi que de leurs volumes de stockage attribués.

. Lorsque vous êtes prêt à poursuivre le plan, sélectionnez *Provision* pour commencer à déployer le système de fichiers Amazon FSx for NetApp ONTAP recommandé.
