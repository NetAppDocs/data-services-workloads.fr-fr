= Démarrage rapide pour la migration Amazon EVS
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Commencez avec l'assistant de migration VMware pour déplacer votre infrastructure actuelle vers Amazon EVS en utilisant Amazon FSx for ONTAP comme datastores NFS externes.

Avant de commencer, vous devriez avoir une compréhension de link:../fsx-storage/permissions-reference-fsx.html["autorisations pour NetApp Workload Factory"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"] Connectez-vous à Workload Factory
[role="quick-margin-para"]
Vous devrez link:https://console.netapp.com["connectez-vous à la NetApp Console"^]. Si vous n'avez pas de compte, link:https://docs.netapp.com/us-en/console-setup-admin/task-sign-up-saas.html["s'inscrire"^]à NetApp Console d'abord, puis connectez-vous.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"] Ajouter des identifiants et des autorisations
[role="quick-margin-para"]
Choisissez le link:../fsx-storage/permissions-reference-fsx.html["Politiques d’autorisation"] qui répond à vos besoins.

[role="quick-margin-para"]
Si vous choisissez de ne pas accorder d'autorisations, vous pouvez commencer à utiliser Workload Factory for Databases pour copier des exemples de code partiellement complétés à partir de link:../fsx-storage/permissions-reference-fsx.html["Politiques d’autorisation"^].

[role="quick-margin-para"]
Si vous choisissez d'accorder des autorisations, vous devrez link:../fsx-storage/add-credentials.html["ajouter manuellement les identifiants à un compte"] ce qui implique de sélectionner les capacités de workload, telles que Databases et VMware, et de créer les stratégies IAM pour les autorisations requises.

[role="quick-margin-para"]
link:../fsx-storage/add-credentials.html["Découvrez comment ajouter des identifiants et des autorisations"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"] Téléverser les données d'inventaire des machines virtuelles
[role="quick-margin-para"]
Vous pouvez utiliser le centre de planification pour importer les détails d'inventaire de votre environnement de machines virtuelles actuel. Utilisez le script de collecte de données, RVTools ou NetApp Data Infrastructure Insights pour capturer la configuration actuelle de vos machines virtuelles et importer les données dans le centre de planification.

[role="quick-margin-para"]
link:upload-vm-inventory.html["Découvrez comment télécharger les données d'inventaire des VM"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"] Créez un plan de déploiement à l'aide de VMware migration advisor
[role="quick-margin-para"]
Lancez le conseiller de migration VMWare et configurez manuellement l’environnement de VM que vous souhaitez créer sur l’infrastructure Amazon Elastic VMWare Service en utilisant un système de fichiers Amazon FSx for ONTAP comme datastores NFS externes.

[role="quick-margin-para"]
link:launch-migration-advisor-evs.html["Découvrez comment utiliser l'assistant de migration VMware pour créer un plan de déploiement"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinq"] Déployez le système de fichiers FSx for ONTAP recommandé
[role="quick-margin-para"]
Déployez le nouveau système de fichiers FSx for ONTAP qui fournira les banques de données pour vos machines virtuelles dans votre infrastructure Amazon EC2.

[role="quick-margin-para"]
link:deploy-fsx-file-system-evs.html["Découvrez comment déployer votre nouveau système de fichiers FSx for ONTAP"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Six"] Passez en revue les insights bien architecturés pour votre environnement EVS
[role="quick-margin-para"]
Lorsque votre environnement EVS est détecté, Workload Factory effectue automatiquement des analyses quotidiennes bien architecturées afin d'identifier les problèmes de configuration et de fournir des recommandations de remédiation.

[role="quick-margin-para"]
link:view-evs-well-architected.html["Apprenez à mettre en œuvre des configurations bien architecturées"^].
