= Déployez le système de fichiers FSx for ONTAP recommandé
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après avoir vérifié que le système de fichiers FSx pour ONTAP recommandé (ou plusieurs systèmes de fichiers dans certains cas) répond à vos exigences exactes, vous pouvez utiliser Workload Factory pour déployer le système dans votre environnement AWS.

Suivez les instructions dans link:../fsx-storage/create-discover-systems.html["Créez un système de fichiers FSx for ONTAP dans NetApp Workload Factory"^] pour déployer le système de fichiers FSx for ONTAP conformément à la configuration recommandée par Workload Factory. Vous pouvez utiliser les étapes de *création avancée* dans les instructions pour personnaliser entièrement le système de fichiers.
