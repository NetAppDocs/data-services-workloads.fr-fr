= Capturez les configurations de vos machines virtuelles avant de migrer vers VMware Cloud avec des charges de travail VMware
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez utiliser le script Migration advisor VM collector ou RVTools pour capturer les configurations actuelles de vos VM. Nous vous recommandons d’utiliser le script Migration advisor VM collector, car il recueille à la fois les données de configuration et de performance des VM pour le plan le plus précis.

[role="tabbed-block"]
====
.Utilisez le script VM collector de Migration advisor
--
Le script de collecteur de VM Migration advisor de NetApp recueille des informations de configuration des VM à partir de votre vCenter, similaires à celles collectées par RVTools ; il capture toutefois les données de performances actuelles des VM afin de fournir des statistiques réelles sur les IOPS et le débit en lecture et en écriture.

Vous devez démarrer l’assistant de migration pour copier le script de collecteur de VM de l’assistant de migration depuis la fenêtre Codebox.

.Avant de commencer
Le système sur lequel vous exécuterez le script de collecte doit répondre aux exigences suivantes :

* Microsoft PowerShell 7.0 ou version ultérieure doit être installé. Consultez  https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell?view=powershell-7.4["documentation Microsoft PowerShell"^] si vous devez installer PowerShell.
* VMware PowerCLI doit être installé. Consultez la documentation https://docs.vmware.com/en/VMware-vSphere/7.0/com.vmware.esxi.install.doc/GUID-F02D0C2D-B226-4908-9E5C-2E783D41FE2D.html["Documentation VMware PowerCLI"^] si vous devez installer PowerCLI.
* La vérification des certificats SSL doit être désactivée.
* PowerShell doit autoriser l'exécution de scripts non signés.


Notez que si vous prévoyez de collecter des statistiques à long terme à partir de vos machines virtuelles (statistiques quotidiennes), vous devez avoir activé le niveau de statistiques 3 ou supérieur dans la console de gestion vSphere (environnement de gestion VMware).

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *VMware*.
+
Le centre de planification est affiché.

. Dans le menu VMware, sélectionnez *Évaluer et planifier*, puis sélectionnez *Migration vers VMware Cloud on AWS*.
+
La page principale de l'assistant de migration VMware s'affiche.

. Sélectionnez *Planifier et créer un VMC*.
. Sélectionnez *Commençons !*. Vous pouvez choisir de ne plus afficher cette page en cochant la case correspondante.
. Sélectionnez *Créer un nouveau plan de déploiement*, sélectionnez l’option *Utiliser le collecteur de données VMware de migration advisor*, puis sélectionnez *Suivant*.
+
La page *Préparer la migration vers VMware Cloud on AWS* s'affiche.

. Dans la fenêtre Codebox, sélectionnez soit image:button-download-codebox.png["le bouton de téléchargement"] pour enregistrer le script du collecteur de VM Migration advisor (nommé « list-vms.ps1 ») sur le système cible, soit image:button-copy-codebox.png["le bouton de copie"] pour copier le script afin de pouvoir le coller sur le système approprié.
. Suivez ces étapes pour capturer les configurations de vos machines virtuelles actuelles :
+
.. Connectez-vous au système sur lequel vous avez téléchargé le collecteur de données et sur lequel PowerShell et PowerCLI sont installés.
.. Connectez-vous à votre serveur VMware vCenter en exécutant la commande suivante :
+
[source, console]
----
Connect-VIServer -server <server_IP>
----
+
Remplacez <server_IP> par l'adresse IP ou le nom d'hôte de votre serveur VMware.

.. Exécutez le script de collecte de données que vous avez téléchargé et spécifiez l’option de collecte de données pour les statistiques de VM « quotidiennes » ou « horaires ».
+
[source, console]
----
./list-vms.ps1 -isLongTermDataCollectionEnabled <true | false>
----
+
où:

+
*** *true* collecte les données d'IOPS et de débit des dernières 24 heures à intervalles de 5 minutes
*** *false* collecte les données d’IOPS et de débit de la dernière heure à intervalles de 20 secondes.






.Résultat
Le script génère un fichier CSV nommé `list-vms-yyyy-MM-dd-HH-mm-ss.csv` dans le répertoire de travail courant. Le fichier CSV contient une liste de toutes les machines virtuelles et de leurs propriétés, ainsi que de leurs données d’IOPS et de débit.

--
.Utilisez le logiciel RVTools
--
RVTools est une application Windows qui interagit avec VCenter et le serveur ESX (5.x à 8.0) pour collecter des informations sur vos environnements virtuels VMware. Elle recueille des informations sur les VM, le CPU, la mémoire, les disques, les clusters, les hôtes ESX, les datastores, et bien plus encore. Vous pouvez exporter ces informations vers un fichier xlsx pour les utiliser avec le conseiller de migration.

link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["Apprenez-en davantage sur RVTools"^]

.Étapes
. Téléchargez et installez RVTools 4.4.2 ou une version supérieure dans le link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["Site web RVTools"^]
. Lancez RVTools et connectez-vous au VCenter Server cible.
+
Cela permettra de recueillir des informations sur ce VCenter Server.

. Exportez vos informations VMware vers un fichier xlsx ou xls.
+
Consultez le chapitre sur les « paramètres de ligne de commande » dans le link:https://www.dell.com/en-us/shop/vmware/sl/rvtools["Documentation de RVTools dans la section Ressources"^] pour plus de détails.



.Résultat
Le fichier xlsx ou xls contenant vos résultats est enregistré dans votre répertoire de travail.
