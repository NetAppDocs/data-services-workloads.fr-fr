= Démarrage rapide pour la migration vers Google Cloud VMware Engine à l'aide de l'advisor de migration des workloads VMware
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Commencez par utiliser l'assistant de migration VMware pour transférer votre infrastructure actuelle vers Google Cloud VMware Engine en utilisant Google Cloud NetApp Volumes comme datastores NFS externes.

Avant de commencer, vous devriez avoir une compréhension de link:../fsx-storage/permissions-reference-fsx.html["Autorisations FSx for ONTAP pour NetApp Workload Factory"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"] Connectez-vous à Workload Factory
[role="quick-margin-para"]
Vous devrez link:../setup/sign-up-and-log-in.html["Configurez un compte avec Workload Factory"^] et vous connecter à NetApp Console.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"] Ajouter des identifiants et des autorisations
[role="quick-margin-para"]
Choisissez le link:../fsx-storage/permissions-reference-fsx.html["Politiques d’autorisation"] qui répond à vos besoins.

[role="quick-margin-para"]
Si vous choisissez de ne pas accorder les autorisations, vous pouvez commencer à utiliser Workload Factory pour VMware pour copier des exemples de code partiellement complétés.

[role="quick-margin-para"]
Si vous choisissez d'accorder des autorisations, vous devrez link:../fsx-storage/add-credentials.html["ajouter manuellement les identifiants à un compte"] notamment fournir un compte de service GCP disposant des autorisations nécessaires pour consulter et gérer les ressources Google Cloud NetApp Volumes, la configuration VPC et la connectivité au datastore Google Cloud VMware Engine.

[role="quick-margin-para"]
link:../fsx-storage/add-credentials.html["Découvrez comment ajouter des identifiants et des autorisations"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"] Téléverser les données d'inventaire des machines virtuelles
[role="quick-margin-para"]
Vous pouvez utiliser le centre de planification pour importer les détails d'inventaire de votre environnement de machines virtuelles actuel. Utilisez le script de collecte de données, RVTools ou NetApp Data Infrastructure Insights pour capturer la configuration actuelle de vos machines virtuelles et importer les données dans le centre de planification.

[role="quick-margin-para"]
link:upload-vm-inventory.html["Découvrez comment télécharger les données d'inventaire des VM"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"] Créez un plan de déploiement à l'aide de VMware migration advisor
[role="quick-margin-para"]
Lancez l'assistant de migration VMware et configurez l'environnement de machine virtuelle que vous souhaitez créer sur l'infrastructure Google Cloud VMware Engine en utilisant Google Cloud NetApp Volumes comme datastores NFS externes.

[role="quick-margin-para"]
link:launch-migration-advisor-gcve.html["Découvrez comment utiliser l'assistant de migration VMware pour créer un plan de déploiement"].
