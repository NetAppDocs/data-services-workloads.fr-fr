= Supprimer un système de fichiers dans NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Pour supprimer un système de fichiers dans NetApp Workload Factory, vous devez d'abord supprimer tous les volumes, les VM de stockage ou les relations de réplication associés au système de fichiers.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. Dans *FSx for ONTAP*, sélectionnez le menu des actions du système de fichiers FSx for ONTAP que vous souhaitez supprimer.
. Sélectionnez *Manage*.
. Dans l'onglet *Aperçu*, sélectionnez le menu des actions.
. Sélectionnez *Delete*.
. Dans la boîte de dialogue Supprimer le système de fichiers FSx pour ONTAP, saisissez le nom du système de fichiers FSx pour ONTAP à supprimer.
. Sélectionnez *Supprimer* pour confirmer.
