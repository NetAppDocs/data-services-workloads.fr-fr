= Accédez aux données de votre système de fichiers FSx for ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez accéder à vos systèmes de fichiers FSx for ONTAP depuis votre infrastructure locale en montant des volumes pour les clients NAS et des LUN iSCSI pour les clients SAN.

link:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/supported-fsx-clients.html["Accès aux données"^] dans la documentation Amazon FSx for NetApp ONTAP, vous trouverez des rubriques expliquant comment accéder aux données à titre de référence.

Vous pouvez également obtenir le point de montage des volumes dans NetApp Workload Factory.



[[get-mount-point-for-volumes-in-netapp-workload-factory]]
== Obtenez le point de montage des volumes dans NetApp Workload Factory

Obtenez le point de montage d'un volume afin de monter un partage sur un partage CIFS ou un client NFS.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *Explorateur de volumes* > *FSx for ONTAP*.
. Sélectionnez le menu actions du volume, puis *Actions de base*, puis *Afficher la commande de montage*.
. Dans la boîte de dialogue de commande de montage, sélectionnez *Copier* pour copier la commande du point de montage NFS ou du partage CIFS. Vous devrez ensuite saisir la commande copiée dans votre terminal.
. Sélectionnez *Fermer*.
