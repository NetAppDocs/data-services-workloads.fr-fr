. Sur la page Créer un système de fichiers FSx pour ONTAP, sélectionnez *Création avancée*.
+
Vous pouvez également charger une configuration enregistrée.

. Dans la section Configuration générale du système de fichiers, veuillez indiquer les éléments suivants :
+
.. *Identifiants AWS* : Sélectionnez cette option pour ajouter des identifiants AWS dans Workload Factory ou continuez sans identifiants.
.. *Nom du système de fichiers*: Entrez un nom pour le système de fichiers.
.. *Région et VPC* : Sélectionnez la région et le VPC pour le système de fichiers.
.. *Type de déploiement* : Sélectionnez un type de déploiement et une génération de système de fichiers. La disponibilité d’un système de fichiers de deuxième génération dépend de la région sélectionnée. Si la région sélectionnée ne prend pas en charge les systèmes de fichiers FSx for ONTAP de deuxième génération, le type de déploiement bascule vers la première génération.
+
*** Déploiement en zone de disponibilité unique (Single-AZ) : assure la disponibilité en surveillant les pannes matérielles et en remplaçant automatiquement les composants d’infrastructure en cas de défaillance. Garantit une haute durabilité grâce à la réplication automatique de vos données au sein d’une zone de disponibilité afin de les protéger contre les pannes de composants.
+
*Génération du système de fichiers* : Sélectionnez une des options suivantes :

+
**** *Deuxième génération* : Cette configuration est recommandée pour les charges de travail à hautes performances ou lorsque les charges de travail commencent modestement et augmentent progressivement jusqu’à un débit de 72 Go/s et 2,4 millions d’IOPS.
**** *Première génération* : Cette configuration est idéale pour les charges de travail nécessitant jusqu’à 4 Go/s ou 160 000 IOPS. Les systèmes de fichiers de première génération permettent uniquement d’augmenter la capacité.


*** Déploiement sur plusieurs zones de disponibilité (Multi-AZ) : assure une disponibilité continue des données même lorsqu’une zone de disponibilité est indisponible. Un système de fichiers Multi-AZ est conçu pour les charges de travail de production stratégiques qui nécessitent une haute disponibilité des données de fichiers ONTAP partagées et un stockage avec réplication intégrée entre les zones de disponibilité.
+
*Génération du système de fichiers* : Sélectionnez une des options suivantes :

+
**** *Deuxième génération* : cette configuration à paire haute disponibilité unique est recommandée pour les charges de travail nécessitant un débit allant jusqu’à 6 Go/s ou 200 000 IOPS. Dans un système de fichiers Multi-AZ de deuxième génération, la capacité peut augmenter ou diminuer pour s’adapter aux exigences de la charge de travail.
**** *Première génération* : Cette configuration est idéale pour les charges de travail nécessitant jusqu’à 4 Go/s ou 160 000 IOPS. Les systèmes de fichiers de première génération permettent uniquement d’augmenter la capacité.




.. *Étiquettes* : Vous pouvez éventuellement ajouter jusqu’à 50 étiquettes.


. Dans la section « Détails du système de fichiers », veuillez fournir les informations suivantes :
+
.. *Capacité de stockage SSD* : Saisissez la capacité de stockage et sélectionnez l’unité de capacité de stockage.
+
*** Pour les déploiements de première génération, vous ne pouvez pas réduire la capacité après la création du système de fichiers.
*** Pour les déploiements de deuxième génération, vous pouvez ajuster la capacité.


.. *Capacité de débit par paire haute disponibilité* : Sélectionnez la capacité de débit par nombre de paires haute disponibilité. Les systèmes de fichiers de première génération ne prennent en charge qu’une seule paire haute disponibilité.
.. *IOPS provisionnées* : Sélectionnez l’une des options suivantes :
+
*** *Automatique* : En mode automatique, pour chaque Gio créé, 3 IOPS sont ajoutés.
*** *Configuré par l'utilisateur* : pour l'option configurée par l'utilisateur, saisissez la valeur IOPS.


.. *Identifiants ONTAP* : Facultatif. Saisissez votre nom d’utilisateur ONTAP et votre mot de passe. Vous pouvez définir le mot de passe maintenant ou plus tard.
+
Si l'utilisateur que vous fournissez n'est pas l'utilisateur fsxadmin et que vous devez ultérieurement réinitialiser le mot de passe fsxadmin, vous pourrez le faire depuis la console AWS.

.. *Identifiants de la machine virtuelle de stockage* : Facultatif. Saisissez votre nom d’utilisateur. Le mot de passe peut être spécifique à ce système de fichiers ou vous pouvez utiliser le même mot de passe que celui saisi pour les identifiants ONTAP. Vous pouvez définir le mot de passe maintenant ou ultérieurement.
.. *Configuration SMB/CIFS* : Facultatif. Si vous prévoyez d'utiliser le protocole SMB/CIFS pour accéder aux volumes, vous devez configurer Active Directory pour la machine virtuelle de stockage lors de la création du système de fichiers. Fournissez les informations suivantes pour la machine virtuelle de stockage créée pour ce système de fichiers.
+
... *Domaine Active Directory à rejoindre* : Saisissez le nom de domaine complet (FQDN) de l’Active Directory.
... *Adresses IP DNS*: Saisissez jusqu’à trois adresses IP DNS séparées par des virgules.
... *Nom NetBIOS du serveur SMB* : saisissez le nom NetBIOS du serveur SMB de l’objet ordinateur Active Directory à créer pour votre machine virtuelle de stockage. Il s’agit du nom de cette machine virtuelle de stockage dans Active Directory.
... *Nom d'utilisateur* : Saisissez le nom d'utilisateur du compte de service dans votre Active Directory existant.
+
N'incluez pas de préfixe ni de suffixe de domaine. Pour `EXAMPLE\ADMIN`, utilisez `ADMIN`.

... *Mot de passe*: Saisissez le mot de passe du compte de service.
... *Unité d'organisation* : Facultativement, saisissez le nom de l'unité d'organisation dans laquelle vous prévoyez de créer le compte d'ordinateur pour FSx for ONTAP. L'unité d'organisation est le nom de chemin distinctif de l'unité d'organisation à laquelle vous souhaitez joindre le système de fichiers.
... *Groupe des administrateurs délégués* : Vous pouvez saisir, si vous le souhaitez, le nom du groupe de votre Active Directory qui peut administrer votre système de fichiers.
+
Si vous utilisez AWS Managed Microsoft AD, vous devez spécifier un groupe tel que AWS Delegated FSx Administrators, AWS Delegated Administrators ou un groupe personnalisé disposant d'autorisations déléguées pour l'OU.

+
Si vous rejoignez un Active Directory autogéré, utilisez le nom du groupe dans votre Active Directory. Le groupe par défaut est `Domain Admins`.





. Dans la section Réseau et sécurité, veuillez fournir les informations suivantes :
+
.. *Groupe de sécurité* : Créez ou utilisez un groupe de sécurité existant.
+
Pour un nouveau groupe de sécurité, reportez-vous à <<Security group details,détails du groupe de sécurité>> pour une description des protocoles, des ports et des rôles du groupe de sécurité.

.. *Zones de disponibilité* : Sélectionnez les zones de disponibilité et les sous-réseaux.
+
*** Pour la configuration du nœud 1 du cluster : sélectionnez une zone de disponibilité et un sous-réseau.
*** Pour la configuration du nœud 2 du cluster : sélectionnez une zone de disponibilité et un sous-réseau.


.. *Tables de routage VPC* : Sélectionnez la table de routage VPC pour autoriser l’accès client aux volumes.
.. *Plage d'adresses IP du point de terminaison* : Sélectionnez *Plage d'adresses IP flottantes en dehors de votre VPC* ou *Saisir une plage d'adresses IP* et saisissez une plage d'adresses IP.
.. *Chiffrement* : Sélectionnez le nom de la clé de chiffrement dans la liste déroulante.


. Dans la section Sauvegarde et maintenance, fournissez les informations suivantes :
+
.. *Sauvegardes de volume* : Les sauvegardes automatiques quotidiennes sont activées par défaut. Désactivez si désiré.
+
... *Période de conservation des sauvegardes automatiques* : Saisissez le nombre de jours pendant lesquels conserver les sauvegardes automatiques.
... *Fenêtre de sauvegarde automatique quotidienne* : Sélectionnez soit *Aucune préférence* (une heure de début de sauvegarde quotidienne est sélectionnée pour vous), soit *Sélectionner l’heure de début des sauvegardes quotidiennes* et spécifiez une heure de début.


.. *Fenêtre de maintenance hebdomadaire* : Sélectionnez soit *Aucune préférence* (une heure de début de la fenêtre de maintenance hebdomadaire est sélectionnée pour vous), soit *Sélectionnez une heure de début pour la fenêtre de maintenance hebdomadaire de 30 minutes* et indiquez une heure de début.


. Sauvegardez ou créez le système de fichiers.
