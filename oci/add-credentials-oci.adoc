= Ajouter les informations d’identification Oracle Cloud Infrastructure à NetApp Workload Factory
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Ajoutez et gérez les identifiants de votre fournisseur de cloud afin que NetApp Workload Factory dispose des autorisations dont il a besoin pour déployer et gérer des ressources dans les comptes de votre fournisseur de cloud.

link:permissions-oci.html["Autorisations pour OCI NetApp Storage Service"]

.À propos de cette tâche
Vous pouvez ajouter des identifiants à un compte Workload Factory existant depuis la page Credentials. Cela permet à Workload Factory de disposer des autorisations nécessaires pour gérer les ressources et les processus au sein de votre environnement cloud.

.Avant de commencer
Vous aurez besoin d'identifiants pour vous connecter à votre compte Oracle Cloud Infrastructure.

.Étapes
. Connectez-vous à l' https://console.netapp.com/["Console NetApp"^].
. Dans le menu, sélectionnez *Charges de travail* > *Administration* > *Identifiants*.
. Sur la page Informations d'identification, sélectionnez *Ajouter des identifiants*.
. Sur la page Ajouter les informations d’identification du service de stockage Oracle Cloud Infrastructure NetApp, procédez comme suit :
+
.. Dans la section _Configuration des autorisations_, sélectionnez les autorisations appropriées pour les identifiants du service Oracle Cloud Infrastructure NetApp Storage Service. Les autorisations *Afficher, planifier et analyser* sont définies par défaut. Cette stratégie d'autorisation vous permet de consulter les pools de stockage OCI NSS, d'obtenir des informations sur l'état du système, d'accéder à l'analyse Well-Architected de vos systèmes et d'explorer les possibilités d'économies.
.. Suivez les étapes manuelles fournies à l’aide de Oracle Cloud Console pour terminer la configuration des autorisations pour les informations d’identification OCI NSS.
.. Sous _Nom des informations d'identification_, saisissez le nom que vous souhaitez utiliser pour ces informations d'identification et saisissez l'OCID de la location.


. Sélectionnez *Add*.
