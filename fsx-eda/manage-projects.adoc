= Gérer les projets EDA dans Workload Factory pour EDA
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez gérer les projets EDA pour contrôler la manière dont votre code et vos artefacts sont gérés pour chaque projet dans NetApp Workload Factory for EDA.



[[create-a-project]]
== Créer un projet

Vous pouvez créer un nouveau projet EDA afin de tirer parti des fonctionnalités de protection des données de votre système de fichiers FSx for ONTAP pour votre code et vos artefacts.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *EDA*.
. Sélectionnez *CI/CD*.
. Sélectionnez *Add project*.
. Sur la page Créer un projet, veuillez fournir les informations suivantes :
+
.. *Nom du projet* : Veuillez saisir un nom pour le projet.
.. *Description*: Veuillez saisir une description du projet.
.. *Système de fichiers* : fournissez les éléments suivants :
+
... *Identifiants* : Sélectionnez les identifiants Amazon AWS à utiliser. EDA utilise ces identifiants pour détecter les systèmes de fichiers FSx for ONTAP que vous pouvez utiliser avec ce projet et pour créer des clones et des instantanés de projets.
... *Région* : Sélectionnez la région dans laquelle ce système de fichiers FSx pour ONTAP réside.
... *FSx for ONTAP système de fichiers* : Sélectionnez un FSx for ONTAP système de fichiers à utiliser avec ce projet.
+
Vous ne pouvez sélectionner que les systèmes de fichiers configurés avec un lien. link:../setup/links-overview.html["En savoir plus sur les liens"^].

... *Choisissez un volume* : Sélectionnez un volume sur lequel stocker le projet ; EDA utilise ce volume comme dépôt de logiciels.
+
Vous ne pouvez sélectionner que les volumes configurés en tant que partage NFS.



.. *Politiques opérationnelles* : Définissez des limites pour les clones de projet :
+
... *Durée maximale de conservation (en jours)* : Indiquez le nombre maximal de jours pendant lesquels un clone doit être conservé. Passé ce délai, Workload Factory supprime le clone.
... *Nombre maximal de clones par utilisateur ou groupe* : Saisissez le nombre maximal de clones pouvant être provisionnés pour un utilisateur ou un groupe.
... *Taille maximale du clone en GiB* : Saisissez la taille maximale en GiB d’un clone de projet.


.. *Politiques d'accès* : Accordez explicitement l'accès au projet à des utilisateurs ou à des groupes spécifiques :
+
... *Périmètre d'application de la politique* : Saisissez des adresses IP individuelles ou des plages d'adresses IP pour limiter l'accès au projet à ces seules adresses IP ou plages.
+
Par exemple : `172.16.0.0/24`

... *Identifiants d'utilisateur ou de groupe* : Saisissez les identifiants d'utilisateur ou de groupe pour limiter l'accès au projet à ces seuls utilisateurs ou groupes.
+
Par exemple : `User1234`





. Sélectionnez *Créer*.


.Résultat
Le projet est créé et apparaît dans la liste des projets sur la page Projets.



[[view-existing-projects]]
== Consulter les projets existants

Vous pouvez consulter les projets existants créés dans NetApp Workload Factory pour EDA en suivant ces étapes.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *EDA*.
. Sélectionnez *CI/CD*.
. Sélectionnez *Accéder à la page Projets*.
. Consultez la liste des projets existants sur la page Projets.




[[edit-a-project]]
== Modifier un projet

Vous pouvez modifier les paramètres d'un projet à tout moment.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *EDA*.
. Sélectionnez *CI/CD*.
. Sélectionnez *Accéder à la page Projets*.
. Sur la page Projets, sélectionnez image:icon-action.png["le bouton d'option"] pour le projet que vous souhaitez modifier, puis sélectionnez *Modifier*.
. Apportez les modifications nécessaires à la configuration du projet.
. Sélectionnez *Enregistrer*.




[[view-a-projects-workspaces]]
== Afficher les espaces de travail d'un projet

Un clone ou un instantané d'un projet est appelé espace de travail. Lorsque vous créez un espace de travail, il est conservé aussi longtemps que le permet la politique d'exploitation du projet. Vous pouvez consulter les espaces de travail existants d'un projet en suivant ces étapes.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *EDA*.
. Sélectionnez *CI/CD*.
. Sélectionnez *Accéder à la page Projets*.
. Sur la page Projets, choisissez un projet et sélectionnez *Afficher*.
. Consultez l'état et les détails de tous les espaces de travail de ce projet.
. Si vous voyez des alertes ou des avertissements pour un espace de travail, survolez l'icône d'alerte ou d'avertissement pour en voir la raison.




[[delete-a-project]]
== Supprimer un projet

Vous pouvez supprimer un projet lorsqu'il n'est plus nécessaire en suivant ces étapes.

.Étapes
. Connectez-vous au link:https://console.netapp.com["NetApp Console"^].
. Sélectionnez le menu image:workloads-menu-icon.png["L'icône du menu hamburger permet d'accéder à Workloads, l'élément de menu de Workload Factory"], *Charges de travail* > *EDA*.
. Sélectionnez *CI/CD*.
. Sélectionnez *Accéder à la page Projets*.
. Sur la page Projets, sélectionnez image:icon-action.png["le bouton d'option"]pour le projet que vous souhaitez supprimer.
. Sélectionnez *Delete*.
. Dans la boîte de dialogue de confirmation, sélectionnez *Supprimer*.


.Résultat
Le projet est supprimé, ainsi que tout code ou artefact associé du volume. Les instantanés et les clones du projet sont conservés.
